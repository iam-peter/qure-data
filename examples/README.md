# Example projects

These ship inside Qure Data (**File ▸ Examples**). Opening one copies its
folder to your data directory (`~/.local/share/QureData/examples/` on Linux)
and opens it from there. The copy is refreshed from the app every time you
open it from the menu, so use **Save As** to keep your changes.

A project is a folder with:

```
main.pd             the patch
*.pd                abstractions it uses (found next to the patch)
nodes/nodes.json    its own QML nodes – loaded before the patch opens
nodes/*.qml
```

The `nodes/` folder needs no build step. Edit a `.qml` file and reopen
the patch to see the change.

## Drum machine

A 16-step sequencer playing four synthesized voices: kick, snare, hat and
clap. Each voice is an abstraction in the folder.

- **`[stepgrid]`** (`StepGrid.qml`) stores each row as a 16-bit mask *in its
  own box arguments* (`node.setArg`), so the pattern is saved with the
  patch. With `"loadArgs": true`, the engine sends the masks out when the
  patch loads, even if the grid is never drawn. Click or drag to paint
  cells. The `clear` and `random` messages also work.
- **`[pad]`** (`TriggerPad.qml`): click to play. It flashes whenever its
  voice plays, as an animation driven by `node.received`.
- Timing stays in the engine. `[metro]` steps the sequence, and
  `[>>]`/`[& 1]` test the pattern bits. The grid only displays the
  playhead.

## Wavetable synth

A monophonic synth whose oscillator plays a waveform you draw.

- **`[wavedraw wavetable]`** (`WaveDraw.qml`) works on engine data
  directly. `Qure.readArray(name)` and `Qure.writeArray(name, offset,
  values)` read and write the array, which is saved in the patch. The graph
  below the editor shows the same array updating live. Presets: `sine`,
  `saw`, `square`, `triangle`, `random`.
- **`[adsr]`** (`Adsr.qml`): drag the three handles. Its arguments hold
  A D S R, and they are sent on load. The envelope itself is generated by
  `[vline~]`, sample-accurate.
- The built-in `[kbd]` keyboard and two `[knob]`s control a `[vcf~]`.

## Euclidean ambient

Three rhythm rings play FM bells (`bell.pd`) in a pentatonic scale into a
stereo feedback delay. It starts running when opened, and you hear it once
DSP is on.

- **`[euclid steps hits rotation hue]`** (`Euclid.qml`): drag up or down to
  change the hits, left or right to rotate, and scroll to change the
  length. A QtQuick Shapes polygon connects the hits. `[expr]` in the patch
  uses the same formula as the ring to decide each step.
- **`[plotter]`** (`Plotter.qml`) is a display-only node. It shows a
  scrolling history of the output level, drawn with the GPU `WaveView`
  item.
- The built-in `[xypad]` sets the delay feedback (x) and brightness (y).
